{{ _("Privacy policy") }}

{% trans %}Last updated: {{ last_updated }}{% endtrans %}

{% trans %}dekimasen.app tracks deadlines for Japanese events and sends you a Discord DM before the ones you care about close. To do that it has to store a small amount of information about you. This page says exactly what, why, and for how long, in plain language. The rules for using the service itself are on a separate page — see the terms of service.{% endtrans %}

{{ _("What we collect") }}

  • {% trans %}Your basic Discord account info — your Discord user ID, display name, and avatar ID. We only ask Discord for basic profile access (identify).{% endtrans %}
  • {% trans %}Your timezone — either the one you picked, or the one your browser reported, so deadlines show in your local time alongside JST.{% endtrans %}
  • {% trans %}Your reminder settings — the reminder rules you create, your reminder presets, the tags you subscribe to, and any lottery outcomes you record (applied, won, lost, paid), which the app uses to stop reminding you about rounds you are done with.{% endtrans %}
  • {% trans %}Pending and sent reminders — the queue of reminders scheduled for you, and whether each has been delivered.{% endtrans %}
  • {% trans %}Login sessions — a random session token per login. Only its SHA-256 hash is stored, never the token itself.{% endtrans %}
  • {% trans %}Your calendar feed link, if you create one. We store only a SHA-256 hash. Anyone with the link can see your upcoming deadlines, so keep it private like a password. If you lose it or want to turn it off, create a new link. The old link will stop working.{% endtrans %}
  • {% trans %}Whether Discord can send you DMs — we save one setting when a DM fails so we can explain why reminders stopped.{% endtrans %}
  • {% trans %}What you contributed — if you have editor rights, the events, tags, and edits you made are recorded with you as the author.{% endtrans %}

{{ _("What we do not collect") }}

  • {{ _("No email address. Discord login never hands us one.") }}
  • {{ _("No IP addresses in the database.") }}
  • {% trans %}The bot does not collect message content. It does not have permission to read your messages, server list, or friends.{% endtrans %}
  • {{ _("No analytics, no third-party trackers, no advertising.") }}

{{ _("Why we collect it") }}

{% trans %}We use this information only to send the event deadline reminders you asked for and show you your settings. We do not use it for anything else. We do not use it to build a profile, rate you, or make automated decisions about you.{% endtrans %}

{{ _("Sharing") }}

{% trans %}We do not share your data. We do not sell, rent, or give it to other companies. We only send the information needed to Discord to deliver your DM.{% endtrans %}

{{ _("How long we keep it") }}

{% trans %}We keep your data while your account is active. We back up the database every night in private, encrypted storage. Backups are deleted automatically after 30 days. When you delete your account, your data is removed from the live site right away, but it may remain in backups for up to 30 days.{% endtrans %}

{{ _("Cookies") }}

{% trans %}We use one cookie to keep you signed in. We do not use analytics or tracking cookies, so there is no cookie consent banner.{% endtrans %}
