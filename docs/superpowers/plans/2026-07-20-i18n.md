# Multi-language (EN/ZH/JA) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every piece of app-authored copy (web + Discord) renders in the viewer's language (English default, Mandarin, Japanese), dates render per-locale, editors can enter per-language concert/tag text, and users pick their language via a header switcher / preferences / the welcome wizard.

**Architecture:** Babel/gettext catalogues (`.po`, compiled in memory at startup — no `.mo` on disk, no deploy-ritual change) resolved through a `ContextVar` set per web request by middleware and per recipient by the bot/scheduler. `en` is `NullTranslations` (identity), so default-locale output stays byte-identical and existing tests pass untouched. User-entered text uses parallel columns (`title_zh`, `name_en`, ...) with a `loc` fallback helper.

**Tech Stack:** Python 3.12, FastAPI/Starlette, Jinja2 (`jinja2.ext.i18n`), Babel >= 2.14, SQLAlchemy async + Alembic (SQLite), discord.py, pytest-asyncio.

**Spec:** `docs/superpowers/specs/2026-07-20-i18n-design.md`. Two implementation refinements vs. the spec text (spec amended alongside this plan):
1. **Cookie-as-cache resolution.** The middleware reads only the `lang` cookie → `Accept-Language` → `en` (no per-request DB read). The DB column `users.language` is the durable copy, synced to the cookie at login and on every change, which satisfies the spec's "signed in → User.language" rule without a middleware DB query. Discord always reads the column.
2. **One switcher route.** `POST /language` (public, optional user) sets the cookie always and writes `users.language` when signed in — replacing the spec's separate `/me/language` + `/language` pair. One write path, both behaviors.

## Global Constraints

- `uv run pytest -q` MUST pass and `uv run ruff check .` MUST be clean before every commit.
- The DB stores aware UTC only; never store or compare naive datetimes (invariant 1).
- `en` output must remain byte-identical to current output everywhere — existing exact-substring tests are the regression net and must not be edited to accommodate EN changes (JA/ZH assertions are new tests).
- All new config files (`babel.cfg`) are ASCII-only (owner's GBK-locale Windows). `.po` files are UTF-8 — that is fine; the ASCII rule covers configs.
- `domain/` stays pure: no I/O, no ContextVar, no `app.i18n` import. Formatters take an explicit `locale: str = "en"` parameter.
- Bot and web never contain business logic; `db/service.py` stays discord-free.
- Migration rules: keep the naming convention, replace `app.db.models.UTCDateTime()` with `sa.DateTime()` after autogenerate, remove the `import app.db.models` line, use batch mode semantics as generated. New columns here are plain adds (no `drop_constraint`), so the legacy-anonymous-constraint fixture is not required.
- Sentence case in all UI copy, in every language.
- Supported locales are exactly `("en", "zh", "ja")` — the tuple in `app/i18n.py` is the single source of truth.
- Commit messages end with the project's standard Co-Authored-By / Claude-Session trailer used on this branch.

```python
"""Locale plumbing: gettext catalogues + the active-locale ContextVar.

Top-level (not domain/ -- it does file I/O at startup; not web/ -- the bot
imports it too). `en` is the source language and maps to NullTranslations,
so the default locale is the identity function: English output is
byte-identical to the pre-i18n app, which is what keeps the existing
exact-substring render tests green.

Catalogues are .po files compiled to .mo IN MEMORY at first use -- no .mo
on disk, no compile step in the deploy ritual.
"""

from contextvars import ContextVar
from io import BytesIO
from pathlib import Path

from babel.messages.mofile import write_mo
from babel.messages.pofile import read_po
from babel.support import NullTranslations, Translations

SUPPORTED = ("en", "zh", "ja")

_TRANSLATIONS_DIR = Path(__file__).parent / "translations"
_active_locale: ContextVar[str] = ContextVar("active_locale", default="en")
_null = NullTranslations()
_catalog_cache: dict[str, NullTranslations] = {}


def get_locale() -> str:
    return _active_locale.get()


def set_locale(locale: str) -> None:
    """Set the active locale; anything unsupported falls back to en."""
    _active_locale.set(locale if locale in SUPPORTED else "en")


def _translations_from_po_text(po_text: str, locale: str) -> Translations:
    catalog = read_po(BytesIO(po_text.encode("utf-8")), locale=locale)
    buf = BytesIO()
    write_mo(buf, catalog)
    buf.seek(0)
    return Translations(fp=buf)


def _load(locale: str) -> NullTranslations:
    po_path = _TRANSLATIONS_DIR / locale / "LC_MESSAGES" / "messages.po"
    if not po_path.exists():
        return _null
    return _translations_from_po_text(po_path.read_text(encoding="utf-8"), locale)


def _catalog() -> NullTranslations:
    locale = _active_locale.get()
    if locale == "en":
        return _null
    if locale not in _catalog_cache:
        _catalog_cache[locale] = _load(locale)
    return _catalog_cache[locale]


def reset_catalog_cache() -> None:
    """Test hook: force catalogues to reload from disk."""
    _catalog_cache.clear()


def gettext(message: str) -> str:
    return _catalog().gettext(message)


def ngettext(singular: str, plural: str, n: int) -> str:
    return _catalog().ngettext(singular, plural, n)


def N_(message: str) -> str:
    """No-op extraction marker for module-level dicts (translated at lookup)."""
    return message


_ = gettext


def negotiate(accept_language: str) -> str:
    """First supported language in an Accept-Language header, else en.

    Deliberately simple: entries arrive in the browser's preference order
    in practice, so q-values are not re-sorted. Any zh-* variant maps to zh.
    """
    for part in accept_language.split(","):
        code = part.split(";")[0].strip().lower()
        if not code:
            continue
        primary = code.split("-")[0]
        if primary in SUPPORTED:
            return primary
    return "en"
```

(e) The switcher route, registered inside `create_app` beside `/healthz`:

```python
    LANG_COOKIE_MAX_AGE = 60 * 60 * 24 * 365

    @app.post("/language")
    async def set_language(
        request: Request,
        user: auth.SessionUser | None = Depends(auth.current_user),
        session: AsyncSession = Depends(get_session),
        language: str = Form(...),
        next_url: str = Form("/", alias="next"),
    ):
        """The header switcher's single write path: cookie always; the DB
        column too when signed in (Discord DMs read the column). Public on
        purpose -- anonymous visitors switch the landing/discover/legal pages."""
        if language not in i18n.SUPPORTED:
            raise HTTPException(status_code=422, detail=f"unsupported language: {language}")
        # Local-path redirect guard: same shape as _safe_next but sitewide,
        # since the switcher lives on every page.
        if not next_url.startswith("/") or next_url.startswith("//"):
            next_url = "/"
        if user:
            from app.db.service import ensure_user

            db_user = await ensure_user(session, user.id, user.username)
            db_user.language = language
            await session.commit()
        response = RedirectResponse(next_url, status_code=303)
        response.set_cookie(
            "lang", language, max_age=LANG_COOKIE_MAX_AGE, samesite="lax", path="/",
        )
        return response
```

```python
# Hand-built weekday/month names, same Windows-portability spirit as the
# hand-built day number below: no strftime locale games, no new dependency.
# Index by dt.weekday() (Mon=0). zh uses the bare 一...日 form ("周六" reads
# fine but the compact form matches ticketing-site convention).
_WEEKDAY = {
    "ja": ("月", "火", "水", "木", "金", "土", "日"),
    "zh": ("一", "二", "三", "四", "五", "六", "日"),
}


def _norm(locale: str) -> str:
    return locale if locale in _WEEKDAY else "en"


def fmt_dual(aware_utc: datetime, tz_name: str, locale: str = "en") -> str:
    jst = utc_to_jst(aware_utc)
    local = utc_to_local(aware_utc, tz_name)
    locale = _norm(locale)
    if locale == "en":
        return f"{jst:%a %Y-%m-%d %H:%M} JST ({local:%H:%M %Z})"
    wd = _WEEKDAY[locale][jst.weekday()]
    wrapped = f"({wd})" if locale == "ja" else f"（{wd}）"
    return f"{jst:%Y-%m-%d}{wrapped} {jst:%H:%M} JST ({local:%H:%M %Z})"


def fmt_dual_lines(aware_utc: datetime, tz_name: str, locale: str = "en") -> tuple[str, str]:
    jst = utc_to_jst(aware_utc)
    local = utc_to_local(aware_utc, tz_name)
    locale = _norm(locale)
    if locale == "en":
        date_line = f"{jst:%a} {jst.day} {jst:%b}"
    else:
        wd = _WEEKDAY[locale][jst.weekday()]
        wrapped = f"({wd})" if locale == "ja" else f"（{wd}）"
        date_line = f"{jst.month}月{jst.day}日{wrapped}"
    time_line = f"{jst:%H:%M} JST · {local:%H:%M %Z}"
    return date_line, time_line


def fmt_day_month(aware_utc: datetime, locale: str = "en") -> str:
    jst = utc_to_jst(aware_utc)
    if _norm(locale) == "en":
        return f"{jst.day} {jst:%b}"
    return f"{jst.month}月{jst.day}日"
```

def relative_phrase(anchor_time: datetime, fire_at: datetime) -> str:
    delta = anchor_time - fire_at
    seconds = int(delta.total_seconds())
    if abs(seconds) < 3600:
        return _("now")
    hours = abs(seconds) // 3600

```python
def loc_field(obj, field: str, locale: str) -> str:
    """Viewer-locale variant of a user-entered field, else the original.

    en -> <field>_en, zh -> <field>_zh, ja -> the original (the original IS
    the Japanese-side source; there are no _ja columns). Empty string counts
    as unfilled. No cross-locale chaining -- zh never falls back to en.
    """
    if locale in ("en", "zh"):
        val = getattr(obj, f"{field}_{locale}", None)
        if val:
            return val
    return getattr(obj, field)
```

In `web/app.py`: `templates.env.globals["loc"] = lambda obj, field: i18n.loc_field(obj, field, i18n.get_locale())`.

```python
"""Catalogue completeness: every extracted msgid is translated in ja and zh."""

from io import BytesIO
from pathlib import Path

from babel.messages.extract import extract_from_dir
from babel.messages.pofile import read_po

ROOT = Path(__file__).parent.parent
METHOD_MAP = [("src/app/**.py", "python"), ("src/app/web/templates/**.html", "jinja2")]
KEYWORDS = {"_": None, "gettext": None, "N_": None, "ngettext": (1, 2)}

# msgids deliberately left untranslated (should stay empty; every addition
# needs a comment saying why).
WHITELIST: set[str] = set()


def _extracted_msgids() -> set:
    found = set()
    for _fname, _lineno, message, _comments, _ctx in extract_from_dir(
        str(ROOT), method_map=METHOD_MAP, keywords=KEYWORDS
    ):
        found.add(message if isinstance(message, str) else message[0])
    return found


def _catalogue_msgids(locale: str) -> set:
    po = ROOT / "src" / "app" / "translations" / locale / "LC_MESSAGES" / "messages.po"
    catalog = read_po(BytesIO(po.read_bytes()), locale=locale)
    return {m.id if isinstance(m.id, str) else m.id[0]: m.string for m in catalog if m.id}


def test_ja_catalogue_complete():
    extracted = _extracted_msgids() - WHITELIST
    entries = _catalogue_msgids("ja")
    missing = {m for m in extracted if not entries.get(m)}
    assert not missing, f"untranslated in ja: {sorted(missing)[:20]}"


def test_zh_catalogue_complete():
    extracted = _extracted_msgids() - WHITELIST
    entries = _catalogue_msgids("zh")
    missing = {m for m in extracted if not entries.get(m)}
    assert not missing, f"untranslated in zh: {sorted(missing)[:20]}"
```
