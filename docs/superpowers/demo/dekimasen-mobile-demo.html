Mobile view — every decision, one frame each

Seven phone frames at true 390 px width, on the shipped design tokens (this page follows your light/dark setting, like the app). Each frame demonstrates one agreed decision:

  • Compact header — one-line wordmark, theme + language; account moves into the tab bar's Me.
  • Bottom tab bar — Home / Discover / Tags / Me; editors get a floating + on Home & Discover.
  • Swipeable board — columns keep their identity, next column peeks in, scroll-snap. Try it: frame 1's board actually swipes.
  • Two-line deadline rows — pill + what, then the dual time; capture buttons full-width, 44 px.
  • Discover content-first — search + active filters on one line; the full filter set lives in a bottom sheet.
  • Dialogs become bottom sheets — same markup, phone presentation.
  • Editor stacks — cards single-column, chips wrap, no structural redesign.

Implementation notes: everything above lands as max-width: 700px rules in the existing style.css (Option A — desktop pixels untouched), plus the tab-bar markup in base.html and the Discover filter sheet. "Me" routes to /preferences; signed out, the tab bar shows Home / Discover / Sign in and the FAB disappears (it is editor-only). The board swipe is pure CSS scroll-snap. Sheets are the existing native <dialog> elements restyled under the breakpoint. Toggle your OS or Claude theme to see the dark rendering.
